## 用户确认的视觉例外

- 会员权益不再使用 niucloud 的五种皮肤。用户选择校园零食的白色组合卡片布局，对照 `F:/program/school-shop/apps/miniapp/src/pages/profile/index.vue` 的 `profile-user-card`、`profile-membership`、`profile-assets`、`profile-check-in`。本项目展示自己的会员状态、会员剩余额度、普通积分及有效期；不引入零食豆、优惠券、签到、购物折扣或等级成长值。
- 会员卡片提供标题、副标题、状态/额度/积分/有效期显示、主题配色、强调色、背景、文字色和圆角设置。旧 `memberVariant/memberStyle` 字段仅兼容读取，不再决定皮肤。
- 默认山形图已替换为 `image-placeholder.svg`，使用当前安装的 Lucide image 图标及本项目提示文字；后台与小程序使用同一占位资产，不修改已选择的素材。
- 编辑器外壳沿用本项目组件，尺寸选择为统一选择框。手机外观保留，容器为完整边框预留空间；组件标题栏与画布工具栏均为 48px。样式弹窗操作区使用 ConsoleFormActions。

## 边距和选中框

niucloud 的 `group/index.vue` 和公共模板把正外边距作为底部背景上的留白，负上下边距用于组件叠放。本项目共用 `decorationOuterStyle` / `decorationBlockStyle`，去掉画布额外的 12px 留白；明确设置为 0 的边距不被主题默认值覆盖。编辑器用 375px 设计基准的容器单位，小程序用对应 rpx。

默认值从 ComponentDict 的 template 核对：普通基础组件外边距为 0；图文导航上下各 10；活动魔方上下及左右各 10；图片展播左右 10。会员卡片按用户选择的校园零食布局适配。旧方案自定义值保留，新默认值不自动写入服务器。

选中框画在组件外层内部，包括组件的外部留白；拖动位置与工具条使用同一个外层边界，避免左右边框被滚动容器裁切。

## 静态资产和数据边界

活动魔方、图片展播、公告仍使用参考工程原始示例素材；它们是随客户端发布的内置资产，不是用户上传。所有内置路径由 `decoration-assets.mjs` 白名单限制。布局图标字体来自 `font_3883393_y0ejxoys01.woff2`，组件箭头字体来自 `font_4567203_r3nkqy7l1w.woff2`，均已本地打包，无在线字体回退。小程序字体使用本地 base64 CSS。

旧会员皮肤与旧 figure.png 已无源码引用；本次尝试清理这些文件被自动审批策略拒绝，故保留原文件，不以切换工具的方式重试删除。原参考目录也保持只读。

数据读写、权限、租户/应用隔离、素材选择、版本并发、保存草稿与显式启用沿用本项目。富文本只接受当前站点应用素材引用，服务端清理可执行内容；热区范围、嵌套链接及单例组件同样由服务端验证。会员数据由应用权益适配器读取，不写入装修方案或公共预览。
